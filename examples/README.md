# Examples

This public repository does not include real TMF example files.

## Why real examples are excluded
Real TMF sample files may expose:
- company-specific information
- project identifiers
- site identifiers
- shipment or tracking references
- workflow patterns
- document structures that should not be disclosed in a public repository

## What this repository provides instead
This repository provides:
- the skills specification
- processing logic
- state management model
- exception handling framework
- evaluation and correctness criteria

## Recommended private validation approach
For internal or private validation, use:
- synthetic PDF samples
- redacted samples
- anonymized mock data
- internally approved validation fixtures
